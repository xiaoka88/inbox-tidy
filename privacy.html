Privacy Policy

Last updated: 13 October 2026

Inbox Tidy ("the tool") is personal software that runs on the author's own computer. It has a single user — the author — and no other accounts, no sign-up, and no multi-user features. This policy describes how the tool handles Google user data.

Summary
  • The tool processes the author's own Google data, on the author's own machine.
  • No Google user data is transmitted to, stored on, or shared with any third party.
  • No data is used for advertising, profiling, or training machine-learning models.
  • Credential material (OAuth tokens) is stored locally in a file readable only by the author's macOS user account.

1. What data is accessed

After you authorise the tool with your Google Account, it may access the following, and only for the author's own account:

  • Gmail (gmail.readonly, gmail.modify, gmail.send, gmail.settings.basic): message lists, message headers, short body previews, labels, and message state. Used to classify bulk mail, apply labels, move selected messages to the trash, and — only when explicitly instructed — send mail.
  • Calendar (calendar): events and calendars, used to read and schedule the author's own appointments.
  • Drive, Docs, Sheets (drive, documents, spreadsheets): files created by or shared with the author, used to store and read notes and reports that the author creates with the tool.
  • Contacts (contacts.readonly): contact names and addresses, read-only, used to match message senders to known people.

2. How the data is used

Data is used solely to perform the tasks the author asks for on their own account: grouping and cleaning bulk mail, keeping notes and schedules, and producing summaries of their own inbox. Every write operation (applying a label, moving a message to the trash, sending mail, creating an event) is performed only after the author explicitly confirms the specific change.

3. How the data is stored and protected

The tool does not operate any server and does not maintain any database of Google user data. Summaries produced during a run are written as ordinary files on the author's own computer, and message content is not retained beyond the run that requested it. OAuth credentials are stored locally in ~/.hermes/google_token.json, protected by the operating system's file permissions and never transmitted anywhere except to Google's own OAuth endpoint.

4. Sharing

No Google user data is sold, transferred, disclosed, or otherwise shared with any third party. The only outbound network requests are to Google APIs (*.googleapis.com, accounts.google.com) using the authorisation granted to the tool. There are no analytics, trackers, or advertising integrations.

5. Retention and deletion

Because the tool keeps no server-side copy, there is nothing to delete remotely. Local working files can be removed at any time by the author. Access can be revoked at any time at myaccount.google.com/permissions or with the tool's own --revoke command; once access is revoked, the tool can no longer read the account.

6. Google API Services User Data Policy

Inbox Tidy's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide the user-facing features described above.
  • Google user data is not transferred to third parties except as necessary to perform those features, to comply with applicable law, or as part of a merger or acquisition approved by Google's policy.
  • Google user data is not used for serving advertisements.
  • No humans read the data other than the author — who is the sole user of the tool — and no data is used to train or improve generalised machine-learning models.

7. Children

The tool is personal software for one adult user. It is not directed at children and does not knowingly process data of anyone under 13.

8. Changes

If this policy changes, the "Last updated" date above changes with it. Because the tool has a single known user, changes are communicated to that user directly.
